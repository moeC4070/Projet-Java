💊 Pharmacie — Application de gestion en Java

Une application Java conçue pour faciliter la gestion d'une pharmacie dans le cadre d'un projet de développement logiciel.

📌 Présentation du projet

Pharmacie est un projet développé en Java dont l'objectif est de proposer une solution informatique pour la gestion d'une pharmacie.

Ce projet permet de mettre en pratique les concepts fondamentaux de la programmation Java, l'organisation d'un projet logiciel et la conception d'une application.

🎯 Objectifs
Développer une application en Java.
Organiser le code selon une structure claire et maintenable.
Mettre en pratique les principes de la programmation orientée objet.
Concevoir une solution adaptée aux besoins de gestion d'une pharmacie.
🛠️ Technologies utilisées
Langage : Java
Environnement de développement : IntelliJ IDEA
Gestion du code source : Git et GitHub

Les technologies et bibliothèques exactes seront précisées après vérification du code source.


🚀 Installation et exécution
Prérequis
Un JDK compatible avec le projet.
IntelliJ IDEA ou un autre IDE compatible avec Java.
Git pour cloner le dépôt.
1. Cloner le dépôt
git clone https://github.com/moeC4070/Projet-Java.git

2. Ouvrir le projet
Ouvrir IntelliJ IDEA.
Sélectionner Open et choisir le dossier Projet-Java.
Configurer le JDK approprié.
Vérifier que les bibliothèques du dossier lib/ sont correctement configurées.
3. Lancer l'application

Repérer la classe principale contenant la méthode main, puis exécuter cette classe depuis l'IDE.
